# ResumeLab_Support

The Resume Lab website, served by GitHub Pages from `main`.

- `app.html`: the marketing page (the App Store's developer website link)
- `index.html`: support and FAQ (the App Store's support link)
- `privacy.html`: the privacy policy (the App Store's privacy link)
- `media/`: screenshots, the web video and icons, made from the 1.2 App Store captures
